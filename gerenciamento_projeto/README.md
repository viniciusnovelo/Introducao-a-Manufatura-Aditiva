# Gerenciamento do Projeto

Este diretório contém toda a documentação de gestão do projeto de extensão, baseada em frameworks ágeis (Scrum) para garantir a entrega de valor contínua durante o planejamento do minicurso.

## 🗂️ Organização das Pastas

- **`/atas_de_reunioes`**: Registros formais das decisões tomadas e alinhamentos da equipe (ex: `ATA DE REUNIÃO_11-05-2026.pdf`).
- **`/marcos`**: Entregas principais que validam o avanço do projeto (Marco 1, Marco 2, etc.).
- **`/sprints`**: Relatórios de planejamento, revisão e retrospectiva de cada ciclo de desenvolvimento (Sprint 1, Sprint 2, etc.), elaborados para acompanhar o progresso das tarefas da equipe
