# Minicurso: Introdução à Manufatura Aditiva

Bem-vindo ao repositório oficial do projeto de extensão **Introdução à Manufatura Aditiva e Modelagem 3D**. 

Este projeto foi desenvolvido com o objetivo de oferecer capacitação tecnológica acessível para o público externo ao IFMG - Campus Betim, introduzindo conceitos fundamentais de modelagem tridimensional e operação de impressoras 3D. 

## 📂 Estrutura do Repositório

O repositório está dividido em duas frentes principais:
- **`/materiais_do_curso`**: Contém a apostila de apoio e os slides/arquivos utilizados em cada um dos 5 dias de aula.
- **`/gerenciamento_projeto`**: Documentação da metodologia ágil (Scrum) utilizada pela equipe, contendo atas de reuniões, relatórios de sprints e definição de marcos.
